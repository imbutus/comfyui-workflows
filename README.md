# Imbutus — ComfyUI Workflows

Ready-made ComfyUI example workflows for the media bundles on **[imbutus.com](https://imbutus.com)** — uncensored image, video, and voice generation on on-demand GPUs.

Each folder is one bundle. To use a workflow, drag its `.json` onto the ComfyUI canvas (or **Workflows → Open**). Inside every media bundle these same workflows are also preloaded in the ComfyUI **Workflows** panel.

## Bundles

| Folder | Bundle |
| --- | --- |
| `image-flux2klein` | FLUX.2 klein — text→image, multi-reference editing, RefControl, face-swap |
| `image-qwen2512` | Qwen-Image-2512 / Edit-2511 — generate + prompt-based editing, multi-angle camera |
| `image-ideogram4` | Ideogram 4 — typography-strong text→image, regional layout |
| `image-boogu` | Boogu-Image — fast Turbo + instruction editing, bilingual text |
| `image-krea2` | Krea-2 — photorealistic 2K text→image with style LoRAs |
| `video-minimaxh3` | MiniMax H3 — video with native stereo audio, text/image/reference driven (MiniMaxDirector timeline) |
| `video-sulphur2` | Sulphur-2 — text/image/audio/video → video (LTX Director 2.0) |
| `video-scail2` | SCAIL-2 — character animation & replacement (Wan2.1 14B) |
| `voice-fishs2` | Fish Audio S2 — TTS + voice clone, voice↔SRT |
| `voice-cosyvoice3` | CosyVoice 3 — TTS, voice clone/convert, voice↔SRT |
| `voice-qwen3tts` | Qwen3-TTS — voice design + 3-second clone, voice↔SRT |
| `voice-chatterbox` | Chatterbox Multilingual — TTS + clone + conversion, 23 languages |
